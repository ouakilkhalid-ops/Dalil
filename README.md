تطبيق Android لتسيير التيليفون:
- 📞 المكالمات: السجل، المدة، النمر غير المسجلة، والشرونو فوق الشاشة أثناء المكالمة
- 📱 التطبيقات: الأيقونة، آخر مرة تحلّات، شحال هادي، وحذف
- ⏰ فكّرني من بعد: أي عدد ديال الدقايق (20د، 45د...)
- 💰 المصاريف: إحصائيات الشهر، الميزانية، واقتراحات
- ⚙️ الأذونات، إعدادات Xiaomi، السكوت فالليل

## كيفاش تخرج APK
**بـ GitHub (بلا PC قوي):** حط هاد الملفات فـ repo جديد → Actions → "Build Santojan APK" → Artifacts → Santojan-APK.

**بـ Android Studio:** File → Open → دوسي Santojan → Build → Build APK(s).
